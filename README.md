# Exercícios de Python — Disciplina de Inteligência Artificial

Este repositório contém os exercícios desenvolvidos durante a disciplina de **Inteligência Artificial** do curso de **Engenharia de Software**.

Os exercícios têm como objetivo praticar os fundamentos da linguagem Python e desenvolver a lógica de programação por meio da resolução de diferentes problemas.

## 📚 Conteúdo

Durante os exercícios foram trabalhados diversos conceitos de programação, incluindo:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Estruturas condicionais (`if`, `elif` e `else`)
* Estruturas de repetição (`for` e `while`)
* Listas e dicionários
* Manipulação de strings
* Funções
* Funções recursivas
* Matrizes
* Busca e ordenação
* Algoritmos como Bubble Sort e Insertion Sort
* Fibonacci
* Números primos
* Cifra de César
* Jogos simples
* Geração de senhas
* Manipulação e análise de dados
* Gráficos utilizando `matplotlib`
* Cálculos estatísticos

## 📁 Arquivos

O repositório contém notebooks desenvolvidos no **Google Colab**, no formato `.ipynb`.

Cada notebook contém os exercícios realizados durante a disciplina, juntamente com seus respectivos códigos e resultados.
